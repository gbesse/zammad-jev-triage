# Security / Sécurité / Seguridad

Store `TYPESAFE_API_KEY` and host credentials only in server environment variables. Treat input text and decisions as sensitive. Restrict outbound access to the pinned TypeSafe API and your configured host API. Webhook integrations require their configured signature secret.

Conserver `TYPESAFE_API_KEY` et les identifiants hôte uniquement dans l’environnement serveur. Traiter les textes et décisions comme sensibles. Vérifier la signature des webhooks.

Guarda `TYPESAFE_API_KEY` y las credenciales del host solo en variables del servidor. Trata textos y decisiones como datos sensibles. Verifica la firma de los webhooks.
